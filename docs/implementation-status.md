# 功能与验证范围

当前实现支持多 IDL ZIP 导入、Consul 契约持久化、动态 HTTP 路由、OpenAPI 文档和独立授权的 MCP 服务。

- 下载链接仅用于一次导入，不存储；重启及其他副本从 Consul 恢复契约。
- HTTP、控制台及 MCP 使用独立端口；默认分别为 8080、9090、8081。
- 更新经过完整校验和 Consul CAS，失败保留已有运行版本。
- 测试覆盖路由冲突、契约损坏、重启恢复、业务错误、身份透传、MCP 授权及在途请求生命周期。
- `go test ./...` 使用本地模拟服务；真实后端测试需要显式选择应用和接口。
- GitHub Actions 运行状态以仓库实际 workflow run 为准；本地测试不代表镜像发布或 Kubernetes 部署成功。

构建和测试命令、运行依赖及部署步骤见根目录 README。
